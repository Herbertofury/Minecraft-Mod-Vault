## Important lineage / safety notes

- Feather is historical identity; current recommendation/download path is Dawn.
- PojavLauncher lineage now points toward AngelAuraMC/Amethyst for current Android/iOS Java-launcher development.
- Badlion remains a distinct client, but its current site documents launchability through Lunar Client.
- BedrockLauncher is unofficial. Back up Bedrock worlds before using alternate version-management tooling and follow its installation requirements carefully.
- SKlauncher documentation warns about impersonation/fake download sites; use the canonical `skmedix.pl` path only.
- Prefer official project domains or canonical GitHub releases for every launcher because these applications handle Microsoft/Minecraft authentication tokens and local game data.
