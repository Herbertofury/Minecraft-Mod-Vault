# Minecraft Mod Vault 0.5.0

Release date: 2026-08-18

## New mega-mod vault

Version 0.5.0 expands Minecraft Mod Vault far beyond furniture/CIT without removing the existing catalog. A new Amazing Mods workspace adds first-class categories for:

- Railroads and trains
- Vehicles, ships, aircraft, and physics contraptions
- Technology and automation
- Magic and spellcraft
- Living foliage, waving grass, leaves, and wind motion
- Particle effects, water splashes, wakes, waterfalls, weather, and ambience
- Card games, trading cards, albums, booster packs, and collectibles
- Tameable pets, companions, animal care, and rideable creatures
- Creature collecting and Pokemon-like gameplay
- Cozy farming, cooking, tea, vineyards, and cottage food systems
- Exploration, world generation, biomes, caves, structures, and dungeons
- Building blocks, architecture, chiseling, shapes, and decoration
- Storage, backpacks, travel, recipes, tooltips, and everyday quality of life
- New mobs and boss fights
- Performance, shader support, rendering, memory, and FPS optimization

The catalog contains curated high-value projects plus live category search so new releases remain discoverable. Modrinth-backed entries keep one-click version/loader-aware installation with required dependency resolution and hash verification. Resource packs and shaders use their correct install targets.

## UI

- Added a dedicated Amazing Mods navigation workspace.
- Added category cards with counts and icons.
- Added category + text filtering.
- Added Search this category live, which hands the selected category directly to the existing native Modrinth browser.
- Added inline train, vehicle, ship, aircraft, gear, computer, rocket, wand, leaf, water, card, paw, creature-collecting, crop, compass, building, backpack, boss, and performance icons.
- Updated Home to surface the expanded catalog and favorite picks.

## Existing features preserved

CIT, furniture, Bedrock, local import, manager, source hubs, settings, Modrinth installer, dependency resolution, file hashing, enable/disable, and vault-trash behavior remain intact.
