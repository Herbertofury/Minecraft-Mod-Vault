# 🤝 Contributing

Minecraft Mod Vault values **reproducible fixes and evidence** over speculative rewrites.

## Strong contribution

A high-quality change includes:

- exact problem/reproducer;
- source/target Minecraft + loader versions;
- scoped implementation;
- tests/fixtures;
- before/after behavior;
- limitations;
- provenance/license notes for reused ideas/code;
- no unrelated feature removal.

## Research contributions

When adding a tool/project to the catalogue, record why it is relevant, current maintenance state, version/date, license and what idea is being studied. A link dump is not enough.

## Documentation contributions

Keep shipped vs planned status honest. Do not upgrade a badge because a feature “should work.”
