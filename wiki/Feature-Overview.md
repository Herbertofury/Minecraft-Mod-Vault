# ✨ Feature Overview

## Current product pillars

| Pillar | What it does | Status |
|---|---|---|
| **OmniManager** | One local identity across Modrinth, CurseForge, GitHub/GitLab and Bedrock content; updates, enable/disable, recovery and provenance. | 🟢 Current `main` identity |
| **Repair Lab** | Hardened source/project repair pipeline with immutable originals, build-contract detection, staged changes, verification and rollback. | ✅ Verified 0.9.0 evidence |
| **Porting Lab** | Installed-JAR forensics, migration planning and isolated upgrade/downgrade workspaces. | ✅ Verified 0.9.0 evidence |
| **Compatibility Brain** | Durable searchable migration/repair knowledge with exact version context. | ✅ Verified 0.9.0 evidence |

## The core promise

Minecraft Mod Vault should answer four questions before it changes anything:

1. **What is this artifact/world really?**
2. **Where did it come from and what does it depend on?**
3. **What exactly will change?**
4. **What evidence proves the result still works?**
