# 📖 Glossary

| Term | Meaning in Minecraft Mod Vault |
|---|---|
| **Artifact** | A local JAR, pack, add-on, world, template, schematic or generated output. |
| **Evidence** | Hash, manifest, provider ID, source URL, runtime result or other fact used to establish identity/correctness. |
| **Provenance** | Where something came from and what transformations produced the current result. |
| **OmniManager** | Cross-store/local artifact management layer. |
| **Repair Lab** | Hardened project repair workflow. |
| **Porting Lab** | Version/loader port analysis and migration workspace. |
| **Compatibility Brain** | Durable searchable compatibility/migration knowledge. |
| **OmniBridge** | 0.11.0 semantic conversion/migration feature expansion. |
| **WorldForge** | Planned universal world editor/converter/repair/retrogen studio. |
| **TestGrid** | Planned tiered QA system with disposable real runtimes. |
| **Agent Test Driver** | Planned player-like real-client testing bridge. |
| **WorldGraph** | Planned version-independent semantic world representation. |
| **Truth Profile** | Clean exact target runtime used as correctness oracle. |
| **Accelerated Profile** | Faster test profile only trusted after matching Truth Profile behavior. |
