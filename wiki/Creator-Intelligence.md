# 📺 Creator Intelligence

> **Status:** 📋 Premium first-class OmniBridge roadmap.

Creator Intelligence connects **mods**, **mod authors**, and **video creators** without pretending they are the same identity.

## Universal project tracking

Track Java mods, Bedrock add-ons, Marketplace content, CIT packs, resource packs, shaders, datapacks, worlds/maps, modpacks, tools and libraries across legitimate sources such as Modrinth, CurseForge, GitHub/GitLab, official sites and Marketplace listings.

## Follow authors

Author/team profiles should include:

- avatar/banner/art;
- aliases;
- project portfolio;
- latest releases/activity;
- verified public link tree;
- source repositories, docs/wiki, YouTube/Twitch/social links, Patreon/Ko-fi/Discord when public and appropriate.

## Whole-channel intelligence

A single YouTube channel, playlist, video or Short should be able to produce an evidence-backed recommendation catalogue using:

- descriptions;
- chapters;
- public captions/transcripts;
- creator-provided links;
- modpack/collection manifests where accessible;
- exact video/timestamp evidence;
- canonical project resolution + confidence.

Benchmark examples include Enderverse, AsianHalfSquat, Bedrock Princess and similar creators—**as test cases, not hardcoded special cases**.

## Gorgeous Video + Mods Explorer

Show the video/Short beside the resolved mods and allow filtering/sorting by date, Minecraft edition/version, loader, content type, creator, project author, source host, installed/followed state, confidence and update freshness.

Never convert a low-confidence transcript guess into a confirmed mod identity.
