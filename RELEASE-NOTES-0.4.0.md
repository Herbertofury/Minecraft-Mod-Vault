# Minecraft Mod Vault 0.4.0

## Desktop app restoration

- Restored Minecraft Mod Vault as compiled Windows and Linux desktop binaries.
- Embedded the UI in the executable so there is no separate local HTML file to manage.
- Added a loopback backend for real filesystem management and installs.
- Removed the root redirect so the per-run application token is preserved without depending on browser redirect behavior.

## Integrated mod manager

- Added real mods/resourcepacks/shaderpacks scanning.
- Added enable/disable rename workflow.
- Added duplicate-safe local imports.
- Added vault trash for managed files and directories.
- Added Bedrock package staging and OS handoff.

## Live Modrinth integration

- Added live search.
- Added compatible-version resolution by Minecraft version and loader.
- Added required dependency installation.
- Added download size and SHA hash verification.

## CIT Pack Vault

- Expanded to 58 curated engines, helper tools, packs, and live directories.
- Added major cute/cottagecore furniture ecosystems and current 2026 packs.
- Added 149-pack, 90-pack, 47-pack, Mizuno, Modrinth, Planet Minecraft, and Sappy discovery lanes so the catalog does not end at a static list.
- Added CIT List, RP Renames, Resource Items, Variants-CIT, CIT Resewn, and CIT Resewn Continuation references.

## Furniture workspace

- Expanded to 25 furniture/decor entries plus live discovery.
- Added current furniture projects including Furnies, Furniture Expanded, Redecorate, Decorations, Cozy Furniture, MDM, Immersive Furniture, and the major established furniture families.

## Bedrock

- Preserved the requested Bedrock furniture, pets, food, visuals, maps, plushies, hotbar, and cozy roleplay entries in a dedicated workspace.
