# User quality rules

- When the user says **premium**, treat it as a maximum-effort quality, completeness, polish, reliability, and behavioral-fidelity requirement.
- Do **not** mechanically add the word to filenames, versions, artifact names, titles, code identifiers, comments, UI labels, metadata, documentation branding, or release branding unless the user explicitly asks for that wording.
- Fulfill the requested quality in the implementation and verification instead of decorating the output with the adjective.
